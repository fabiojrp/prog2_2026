# Simple E-commerce

Projeto didático utilizando Node.js, Express e EJS.

## Estrutura

- Produtos: cadastro e listagem
- Categorias: cadastro e listagem
- Bootstrap 5
- Dados armazenados temporariamente em arrays
- Formulários utilizando GET, POST e `req.body`

## Como executar

```bash
npm install
npm start
```

Depois acesse:

http://localhost:3000

## Rotas

GET  `/`
GET  `/produtos`
GET  `/produtos/cadastrar`
POST `/produtos/cadastrar`
GET  `/categorias`
GET  `/categorias/cadastrar`
POST `/categorias/cadastrar`
